Preguntas frecuentes

Lo que un cliente probablemente preguntaría.

¿Mirr-X Day necesita internet para funcionar?

Las funciones básicas pueden mostrarse desde el sistema, pero clima, sincronización, actualizaciones y algunas respuestas de IA requieren conexión a internet.

¿Puedo personalizar lo que aparece en el espejo?

Sí. La propuesta incluye una aplicación web para configurar horarios, recordatorios, preferencias, módulos y elementos visibles.

¿El espejo guarda información personal?

Tú decides qué compartir y qué funciones activar. Mirr-X Day está diseñado para ofrecer una experiencia personalizada sin perder de vista la seguridad y privacidad del usuario.

¿Qué pasa si se va el internet?

El espejo podría seguir funcionando como espejo y mantener información local básica. Las funciones que dependan de servicios en línea quedarían temporalmente limitadas.

¿La inteligencia artificial escucha todo el tiempo?

La intención es que la interacción se active únicamente cuando el usuario la solicite. No se plantea una escucha permanente.

¿La instalación está incluida?

Mirr-X Day está pensado para instalarse de forma segura mediante un sistema de montaje diseñado para el espejo. La instalación puede adaptarse al espacio del usuario para asegurar una colocación firme, funcional y estética.

¿Cuál es la diferencia entre Lite, Plus y Pro Max?

Elige la experiencia que mejor se adapte a ti. Las tres versiones mantienen las funciones principales de Mirr-X Day, mientras que Plus y Pro Max ofrecen una pantalla más amplia, mayor rendimiento, mejor experiencia de audio y acabados más avanzados.
